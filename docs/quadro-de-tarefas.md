# Quadro de tarefas (metodologia: Kanban)

Quadro usado na 2ª entrega. Espelha as etapas do trabalho; cada etapa virou um commit pequeno.
Para o quadro "vivo", crie um GitHub Project (Board) no repositório com as colunas
**Backlog → Em andamento → Em revisão → Concluído** e importe os cartões abaixo como issues.

| # | Tarefa | Coluna |
|---|---|---|
| 1 | Model `Instituicao` com `Endereco` (aninhado) e `Contato` (lista) | Concluído |
| 2 | Repository e service de `Instituicao`, com testes | Concluído |
| 3 | Controller, endpoints `/instituicoes` e OpenAPI | Concluído |
| 4 | `Doacao` com `instituicaoId` e validação da instituição | Concluído |
| 5 | Atualizar CLI, testes (controllers) e cobertura | Concluído |
| 6 | Documentação técnica (banco, arquitetura) e README | Concluído |
| 7 | Quadro de tarefas e tag `entrega-2` | Em revisão |
| 8 | Gravar vídeo de demonstração (3 a 5 min) | Backlog |
